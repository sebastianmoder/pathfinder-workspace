# Bundled Pathfinder fonts

These Fontsource WOFF2 files supply typography across the Pathfinder apps.
They are vendored from the package versions below so builds do not need to
download fonts from an external service. Original licences are included
alongside the files; keep them with redistributed font assets.

- atkinson-hyperlegible-next: 5.3.0
- atkinson-hyperlegible-mono: 5.3.0
- zilla-slab: 5.3.0
- geist-mono: 5.3.0

Update these assets explicitly when updating branding, together with the font
declarations in `../styles.css`, and check all affected apps. See the
[workspace README](../../../README.md) for cross-app validation and hosting.
