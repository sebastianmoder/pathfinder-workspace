# Basics of (Generative) AI

Start with the concepts needed to judge an educational use: what the system
produces, what can go wrong, whether the output can be checked, and which
institutional safeguards apply. Use the task checklist before trying a workflow
with students or protected material.

- [What is generative AI?](/genai/what_is_genai) provides a brief introduction to artificial intelligence and generative AI.
- [Limitations and risks](/genai/limitations) explains unsupported output, outdated knowledge, variability, bias, instruction failures, and displaced learning.
- [Why AI detection does not prove authorship](/genai/ai_detection) explains detector scores and fairer responses to authorship concerns.
- [When to use AI](/genai/when_to_use) offers a short task-before-the-task checklist.
- [Responsible AI use](/genai/responsible_use) provides an EU-oriented framework for privacy, high-impact decisions, human oversight, transparency, copyright, and tool selection.
